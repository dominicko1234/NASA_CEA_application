# Application of NASA CEA python

This program uses the python interface of NASA CEA to help determine the following parameters for a rocket engine.

Parameters:

- Oxidiser to Fuel (O/F) ratio // Mixture ratio
- Chamber pressure

## Installation

Create a new virtual environment

```
python3 -m venv .venv
```

Install required libraries using the following command

```
pip3 install -r requirements.txt
```

## Run program

In the same directory as virtual environment, run the following command in terminal or cmd to run the main program

```
python3 main.py
```
